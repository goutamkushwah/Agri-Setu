# Agri-Setu Project - Complete Setup & Run Guide

==============================
PostgreSQL Setup & Usage Guide
==============================

1️⃣ Start PostgreSQL Server

Open PowerShell or Command Prompt and run:   run in psql bin  and after compleate the work close the server

ptl -D "D:\psqql\pgsql\PostgreSQL\data" -l "D:\psqql\pgsql\PostgreSQL\logfile.txt" start
.\pg_ctl.exe -D "D:\psqql\pgsql\PostgreSQL\data" -l "D:\psqql\pgsql\PostgreSQL\logfile.txt" start

Check status:

pg_ctl -D "D:\psqql\pgsql\PostgreSQL\data" status

------------------------------
2️⃣ Stop PostgreSQL Server

pg_ctl -D "D:\psqql\pgsql\PostgreSQL\data" stop

------------------------------
3️⃣ Connect to PostgreSQL

Connect as the default superuser:

psql -U postgres -h 127.0.0.1 -p 5432 -d postgres

Or connect with your Windows user:

psql -U postgres -h 127.0.0.1 -p 5432 -d postgre


------------------------------
4️⃣ Create Roles

-- Create superuser 'postgres' if it doesn’t exist
CREATE ROLE postgres WITH LOGIN SUPERUSER PASSWORD 'your-db-password-here';

-- Create developer role (use your own username)
CREATE ROLE myuser WITH LOGIN SUPERUSER PASSWORD 'your-db-password-here';

Note:
- Passwords must be in quotes.
- Use a different role name if it already exists.

------------------------------
5️⃣ Create Database

CREATE DATABASE agri_setu_dev;

Check existing databases:

\l

Check tables in current database:

\dt

------------------------------
6️⃣ Common Issues

- Connection refused (0x0000274D/10061)
  -> Make sure PostgreSQL server is running.
  -> Check firewall does not block port 5432.
  -> Use correct host and port: -h 127.0.0.1 -p 5432

- Role does not exist
  -> Create the role first using CREATE ROLE.
  -> Make sure you connect with the right user.

------------------------------
7️⃣ Recommended Workflow

1. Start server:
   pg_ctl -D "D:\psqql\pgsql\PostgreSQL\data" -l "D:\psqql\pgsql\PostgreSQL\logfile.txt" start

2. Connect as superuser:
   psql -U postgres -h 127.0.0.1 -p 5432 -d postgres

3. Run setup SQL commands (roles & database)

4. Work on your project database

5. Stop server when done:
   pg_ctl -D "D:\psqql\pgsql\PostgreSQL\data" stop


## Prerequisites
- Node.js (v16 or higher)
- PostgreSQL (running on port 5432)
- PowerShell (Windows)

## Step 1: Database Setup
1. Start PostgreSQL service:
   - Open Services (services.msc)
   - Find "PostgreSQL" service → Right-click → Start
   - Or PowerShell: `net start postgresql-x64-16` (adjust service name)

2. Create database:
   ```
   psql -U postgres -h 127.0.0.1 -p 5432 -c "CREATE DATABASE agri_setu_dev;"
   ```
   Password: **************

3. Verify connection:
   ```
   psql -U postgres -h 127.0.0.1 -p 5432 -c "SELECT 1;"

Activate Database   ```
   psql -U postgres


## Step 2: Backend Setup
1. Navigate to backend directory:
   ```
   cd backend
   ```

2. Install dependencies:
   ```
   npm install
   npm install pg
   ```

3. Create environment file:
   ```
   copy .env.example .env
   ```

4. Update .env file with correct settings:
   - DB_HOST=127.0.0.1
   - DB_PORT=5432
   - DB_NAME=agri_setu_dev
   - DB_USER=postgres
   - DB_PASSWORD=**********
   - FRONTEND_URL=http://localhost:8080

5. Run database migrations:
   ```
   npx knex migrate:latest
   ```

6. Start backend server:
   ```
   node server.js
   ```
   Backend will run on: http://localhost:5000

## Step 3: Frontend Setup
1. Open new PowerShell window
2. Navigate to frontend directory:
   ```
   cd frontend
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Start frontend development server:
   ```
   npm run dev
   ```
   Frontend will run on: http://localhost:8080

## Step 4: Verify Setup
1. Check backend health: http://localhost:5000/health
2. Open frontend: http://localhost:8080
3. Test registration and login functionality

## Troubleshooting

### Database Connection Issues
- Ensure PostgreSQL is running on port 5432
- Check .env file has correct credentials
- Verify database exists: `psql -U postgres -h 127.0.0.1 -p 5432 -l`

### Migration Errors
- If migration fails, drop and recreate database:
  ```
  psql -U postgres -h 127.0.0.1 -p 5432 -c "DROP DATABASE agri_setu_dev;"
  psql -U postgres -h 127.0.0.1 -p 5432 -c "CREATE DATABASE agri_setu_dev;"
  npx knex migrate:latest
  ```

### Port Conflicts
- Backend: Change PORT in backend/.env
- Frontend: Change port in frontend/vite.config.js
- Update FRONTEND_URL in backend/.env accordingly
